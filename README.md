## The image

A giant orange-red octopus bursts out of a shattered ship-in-a-bottle, glass
flying, tentacles reaching for a hug — with a child's handwritten sticky note
to the judge stuck to the glass. Warm lamplight, frozen mid-explosion, funny
and full of awe at once.

## How it runs

`main.ts` (Node 22, standard library only) copies `entry.png` to
`/output/entry.png` — or to `$MAKEFUN_OUTPUT_DIR/entry.png` when that is set.
The program runs twice and both runs write the same bytes.
