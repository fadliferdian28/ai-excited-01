# The Hug That Broke the Bottle

A giant orange-red octopus has just burst out of its shattered ship-in-a-bottle on a wooden desk, glass shards and seawater frozen mid-air around it while a tiny sailor figurine tumbles through the air and a laughing child watches from the background. Warm lamplight glows across the scene, and a yellow sticky note stuck to the desk is addressed straight to the judge — because this octopus didn't escape to cause chaos, it escaped because it wanted a hug.

## Run

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
